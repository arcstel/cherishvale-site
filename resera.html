Questions

Do I need the password?

Yes. Resera removes a password you already know. It is not a password cracker and cannot recover a password you have forgotten.

What about PDFs I can open but can't print or copy?

Those carry only owner restrictions rather than an open password. Resera removes those in one click, with no password required.

Is it really offline?

Completely. Resera makes no network requests — no telemetry, no accounts, no update pings. You can run it with the network disconnected.

Which systems?

Windows, macOS and Linux, from a single codebase.

On privacy

Resera runs entirely on your machine. Unlocking a PDF opens the file, removes the password and writes a copy beside it; the original is never modified. No file, filename or password is ever transmitted, logged or stored anywhere.
